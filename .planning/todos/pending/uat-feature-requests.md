## Feature Requests

### 1. Task Due Dates
Tasks should have an optional due date so assignees know when things need to be done.

### 2. Welcome Email
New users should receive a welcome email after signing up — onboarding, setting expectations, bee-themed tone.

### 3. Task Description / Instructions
Tasks currently have only a 160-char text field. Add a longer description or instructions field so the Queen can explain what needs to be done in detail for the worker bee.

### 4. Task Categories / Tags
Group tasks into buckets like housekeeping, lawn work, finances, etc. Allows filtering and organizing the Honeycomb by category.

### 5. Due Date with Calendar Integration
Extend due dates with calendar integration (Google Calendar, Apple Calendar) so tasks show up on the assignee's calendar.
