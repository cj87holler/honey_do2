<objective>
Flip `cj87holler/honey_do2` from public to private (SEC-06), without silently losing Phase 11's
merge gate and without misreading a known-broken preview deploy as a broken integration.

Purpose: the repository is currently world-readable. Its entire git history — every commit since
the project started — can be cloned by anyone. SEC-06 closes that. But the flip is a one-command
change to a third-party service with two side effects that produce no error message: on GitHub
Free, private personal repos lose classic branch protection (dropping Phase 11's required `ci`
check and `enforce_admins: true`), and the GitHub→Vercel App integration could in principle lose
access. Neither shows up in the app. Both are only detectable by capturing state before and
reading it back after.

Output: the repo is private; SC1 and SC2 from ROADMAP Phase 13 are both verified from live CLI
output; and the outcome for branch protection and secret scanning is a written, committed fact
rather than an assumption.

**Note on task count:** this plan has four tasks rather than the usual two to three. Every one of
them is a handful of `gh`/`git` calls — the estimated total is roughly 35% context, comfortably
inside budget. The count is driven by mandatory ordering (capture → human gate → flip → tripwire),
not by scope. Collapsing any two of them would either destroy the pre-flip baseline that makes a
silent regression detectable, or bury the human gate inside an autonomous task.

**Note on stack claims:** CLAUDE.md's stack table is stale (it says Next.js 15 + Auth.js v5; the
app is Next.js 16.2.1 + Better Auth 1.5.6). Irrelevant to this phase — no application code is
touched — but do not propagate those version claims into the summary.
</objective>
