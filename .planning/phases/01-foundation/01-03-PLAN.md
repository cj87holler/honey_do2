1. Create `src/lib/actions/hive.ts` — Server Actions for Hive operations:
   ```typescript
   "use server"

   import { auth } from "@/lib/auth"
   import { db } from "@/lib/db"
   import { hives, hiveMembers } from "@/db/schema"
   import { eq, and } from "drizzle-orm"
   import { headers } from "next/headers"
   import { redirect } from "next/navigation"
   ```

   **`createHive(formData: FormData)`** Server Action:
   - Get session via `auth.api.getSession({ headers: await headers() })`. If no session, `redirect("/login")`.
   - Extract `name` from formData. Validate: non-empty after trim, max 100 characters. If invalid, throw Error with message "Give your Hive a name." (empty) or "Hive name must be 100 characters or fewer." (too long).
   - Insert into `hives` table with the name.
   - Insert into `hiveMembers` table with `hiveId`, `userId: session.user.id`, `role: "queen"` (per D-11: creator is always Queen).
   - `redirect(\`/hive/\${hive.id}\`)` per D-02: after creation, land on dashboard.
   - Use `db.insert(hives).values({ name: name.trim() }).returning()` to get the created hive ID.

   **`renameHive(hiveId: string, formData: FormData)`** Server Action:
   - Get session. If no session, throw Error("Unauthorized").
   - Verify user is Queen of this hive by querying `hiveMembers` where `userId = session.user.id AND hiveId = hiveId AND role = "queen"`. If not found or not queen, throw Error("Forbidden").
   - Extract `name` from formData. Validate same as createHive.
   - `db.update(hives).set({ name: name.trim(), updatedAt: new Date() }).where(eq(hives.id, hiveId))`.
   - Use `revalidatePath(\`/hive/\${hiveId}\`)` to refresh the page data.

   **`requireQueen(hiveId: string)`** helper (exported, reusable for future phases):
   - Get session via `auth.api.getSession({ headers: await headers() })`. If no session, throw Error("Unauthorized").
   - Query `hiveMembers` for matching userId + hiveId.
   - If not found or role !== "queen", throw Error("Forbidden").
   - Return `{ session, member }`.

   **`getHiveWithMembers(hiveId: string)`**:
   - Query `hives` by ID.
   - Query `hiveMembers` where `hiveId` matches, joined with `user` table to get name and email.
   - Return `{ hive, members }` where members is an array of `{ id, name, email, role, honeyCount, joinedAt }`.

   - Query `hiveMembers` where `userId` matches, take the first result (D-04: one hive per user).
   - Return the `hiveId` or null if user has no hive.
   - This is used by the routing logic to determine if user needs /hive/create or /hive/[id].
