## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|

| Label | 14px (text-sm) | 400 (regular) | 1.25 |

Notes:
- Member name in leaderboard row: 16px / weight 400 / `text-bee` — matches existing member-list pattern.

- Rank number: 14px / weight 600 / `text-stone-400` for ranks 2+ ; `text-honey` for rank 1 — differentiates top spot without a dedicated color token.
- Section heading "Leaderboard": 20px / weight 600 / `text-bee` — matches existing `MemberList` heading (`text-xl font-semibold text-bee`).

Source: Extracted from existing components (member-list.tsx, task-card.tsx, honeycomb.tsx).

## Component Inventory

### New Component: `<Leaderboard>`

**File:** `src/components/hive/leaderboard.tsx`
**Replaces:** `src/components/hive/member-list.tsx` (D-02 from CONTEXT.md)

**Props:**
```
members: Array<{ id, name, role, honeyCount }>
isQueen: boolean
hiveId: string
```

**Anatomy (top to bottom):**
1. Section heading — "Leaderboard" — `text-xl font-semibold text-bee mb-3`
2. Ranked member list — sorted by `honeyCount` descending, ties get same rank
3. Each row — rank number + crown/bee emoji + member name + role badge + honey score
4. Empty state — shown when all honeyCount values are 0
5. InvitePanel — rendered at bottom when `isQueen && hiveId` (D-03)

**Row anatomy (single leaderboard row):**
```
[rank] [emoji] [name] [RoleBadge]         [honeyCount 🍯]
  14px  emoji   16px   existing badge        14px / amber pill
```

Row styling: `flex items-center justify-between py-2 px-4 bg-stone-50 rounded border-b border-stone-100`

**Rank number rules (D-04, D-05):**
- Sort members by `honeyCount` DESC before rendering
- Assign rank: same score = same rank; next rank skips (1, 1, 3 — not 1, 1, 2)
- Rank 1: render 👑 emoji in place of rank number; apply `font-semibold` to member name
- Ranks 2+: render numeric rank as `text-sm text-stone-400 w-5 text-right`

**Honey score display (D-07):**
- Format: `{honeyCount} 🍯`
- Rendered as amber pill: `inline-flex items-center rounded-full bg-amber-100 px-2 py-0.5 text-xs font-medium text-amber-800`
- This matches the existing honey badge in task-card.tsx exactly

**Reused components:**
- `<RoleBadge role={member.role} />` — imported from `./role-badge`, no changes
- `<InvitePanel hiveId={hiveId} />` — imported from `../invite/invite-panel`, no changes

## Interaction States

| State | Trigger | Visual Treatment |
|-------|---------|-----------------|
| Default row | Idle | `bg-stone-50 border-b border-stone-100` |
| Hover row | Mouse over | `hover:bg-stone-100` transition-colors |
| Rank 1 row | honeyCount is highest | Member name `font-semibold`, 👑 emoji replaces rank number |
| Tie rows | Equal honeyCount | Same rank number displayed for both rows |
| All-zero state | All members have honeyCount = 0 | Empty state message shown below member list (D-10) |
| Loading (invite generate) | Invite button clicked | Delegated to existing InvitePanel — no new loading state needed |

No client-side interactivity required in the leaderboard rows themselves. Leaderboard is a server component. InvitePanel remains a client component as-is.

## Accessibility

|---------|-------------|

| Section | Wrap in `<section aria-label="Leaderboard">` |
