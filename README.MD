# honey_do PRD 

# Intro 
For individuals who live with other humans, whether roommates or significant others, there is always small tasks to do. We ask one another to do things; chores, small tasks, etc. But, we forget. So, we try to get it in writing. Text messages, shared notes, but even then we still forget things. 

# Enter Honey_Do 
Honey_Do is a fun, gamified way to ask and keep track amongst significant others or your friends. 

# Goals 
1. Make to do lists fun 
2. Keep track of asks and to do lists 
3. Compete with completed tasks within a household or across households. 

# Roles 
- <b>Queen</b>: Queens can create and assign tasks. A Queen cannot get assigned a task <i>unless it is assigned from a QueenBee</i>.
- <b>Bee</b>: Bee(s) get assigned tasks from the Queen. They cannot create them.  
- <b>QueenBee</b>: A QueenBee is a special role where they can both <b>create AND assign</b> tasks. This could be a wife & husband where they both want to create and assign tasks to each other. 

# Tasks 
- Tasks are created either by Queens or QueenBees. 
- They should be open text entry, 160 character limit. 
- All tasks must be assigned to a Bee or a QueenBee. A task can't be created if there are no bees or QueenBees.   
- When a task is created, it needs to be assigned a 'honey' value. It could be worth 5, 10, or 20 'honeys'. 
- There also should be a custom option, free entry text up to 60 characters. 
- If a bee or QueenBee is assigned a task, it should show up on their 'honeycomb'. Think of this as their evolving 'to do' list. 
- It should be fun and playful. If a lot of tasks, it should be like 'whoa! better get to work!' | if no tasks 'go play golf!'
- There should be an area for completed tasks. 
- Tasks needs to be able to marked as 'in progess' or 'done' 

# Hive(s) 
- A single instance of Honey_Do is a 'Hive'. 
- Hives can compete with other Hives and make a 'colony'.  
- Queens can name the Hive. 

# Leaderboard 
- In a hive, show leaderboard based on 'honey' earned. 
- If there is a colony, show a joint leaderboard between all Bees and QueenBees.
